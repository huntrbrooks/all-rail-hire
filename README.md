## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Routes

- `/` — Home
- `/about` — About
- `/services` — Services
- `/project` — Projects
- `/capabilities` — Capability statement (Issuu)
- `/contact` — Contact (no form)
